# Melos Companion

**Open it: https://vakilos.github.io/melos-companion/**

Prepare songs and setlists for the [Melos](https://vakilos.github.io/melos-privacy/) Android app on a laptop or tablet: lyrics and notes with chords, sections and rig cues, files and audio, setlists. Export a `.setlist` file and open it with Melos on the phone.

- Works in Chrome, Edge, Safari and Firefox; install it from the browser (Chrome/Edge: the install icon in the address bar; Safari: File → Add to Dock, or Share → Add to Home Screen on iPad/iPhone) to use it offline in its own window.
- Everything stays in your browser. Nothing is sent to a server.

This repository only holds the published website. It is built and updated automatically from the app's own (private) repository.
